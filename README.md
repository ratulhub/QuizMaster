# QuizMaster

QuizMaster is a cinematic, professional-grade university Java web application designed to test your knowledge through dynamic modes and engaging challenges. Built completely with Servlets and JSP, it avoids unnecessary frameworks while delivering a startup-level UI/UX.

## 🚀 Architecture
This project features a clean, monolithic architecture optimized for simplicity and deployment:
- **Frontend**: JSP (JavaServer Pages), CSS3 (Glassmorphism aesthetics), Vanilla JS
- **Backend**: Java Servlets (Jakarta EE 10)
- **Database**: PostgreSQL (Supabase)
- **Deployment**: Render (Tomcat 10.1 + Java 17 via Docker)

## ✨ Features
- **7 Unique Modes**: Normal, Roast, Sudden Death, Teacher Mode, Friend Battle, Bride Interview, Test Myself.
- **Cinematic UI/UX**: Dark mode by default, glassmorphism elements, smooth micro-animations.
- **Admin Dashboard**: Manage users, quizzes, and bulk upload files (TXT/PDF/DOCX).
- **Gamification**: Earn XP, ranks, and track your streaks.
- **Secure Authentication**: SHA-256 password hashing.

## 🛠 Tech Stack
- **Java 17**
- **Maven**
- **Apache Tomcat 10.1**
- **Supabase PostgreSQL**
